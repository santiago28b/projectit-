# 02: Marketplace and Project detail

**What to build:** As Maria, I can browse the Marketplace and see only the Projects I'm eligible for (public, plus restricted ones that match my university, region, or an Invitation). Cards show the Company or Sponsor, skills, expected duration, deadline, and Visibility, and Platform Projects are marked as such. Opening a card shows the Project detail page with the scenario, skills evaluated, expected time, deliverables, and a Start Project button.
